# **App Name**: QuizWhiz

## Core Features:

- Quiz Generation: Generate multiple-choice quizzes based on user-inputted topics, by sending a series of requests to an LLM, framed as 'tool calls'.
- Quiz Display: Display the generated quiz questions and answer options in a clean, user-friendly format.
- Quiz Taking: Allow users to answer quiz questions and track their responses.
- Score Calculation: Automatically calculate the user's score based on their answers.
- Performance Insights: Generate detailed insights into the user's performance, highlighting areas of improvement and strong topics using AI.
- Topic Input: Allow the user to provide the topic or content for which the quiz will be generated.

## Style Guidelines:

- Primary color: Fresh green (#A2FF77) to evoke a sense of learning and growth.
- Background color: Soft white (#F2F2F2) to provide a clean and modern backdrop.
- Accent color: Complementary light green (#C8FFB3) to highlight important elements.
- Body and headline font: 'Inter', a sans-serif font, for a clean, modern feel.
- Use clear and simple icons to represent different quiz topics and functionalities.
- Implement a clean, modern layout with clear sections for quiz questions, answers, and results.
- Incorporate subtle animations for correct/incorrect answers and when generating new quizzes.
